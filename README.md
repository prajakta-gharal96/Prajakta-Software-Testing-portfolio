# Software Testing Portfolio
**Prepared for:** Prajakta Gharal  
**Focus:** Manual Testing, Functional Testing, API Testing, Database Testing, Defect Reporting

## About this portfolio
This portfolio demonstrates testing documentation using a fictional online shopping application named **DemoShop**. All names, records, URLs, test data, and examples are synthetic and created only for demonstration.

## Contents
- `01_Test_Scenarios.csv` – sample high-level test scenarios
- `02_Test_Cases.csv` – detailed manual test cases with expected results
- `03_Sample_Bug_Reports.csv` – illustrative defect reports
- `04_API_Test_Cases.csv` – sample REST API test ideas
- `05_SQL_Testing_Examples.sql` – generic SQL validation examples
- `06_API_Sample_Requests.json` – fictional request/response examples

## Skills demonstrated
Manual Testing, Functional Testing, Positive and Negative Testing, Test Case Design, API Testing concepts, SQL Data Validation, Defect Reporting, Retesting, Regression Testing.

## Important confidentiality note
This is an independent practice portfolio. It contains no employer documents, customer information, production URLs, credentials, source code, screenshots, or proprietary test data. Do not add confidential information from any employer or client.

## How to use
1. Review the scenarios and test cases.
2. Explain the test data, steps, and expected results in an interview.
3. Use the bug reports to explain defect lifecycle and severity/priority.
4. Adapt the SQL examples only to a local practice database with the sample schema you create yourself.

## Scope limitation
These are sample practice artifacts, not evidence that these exact tests were executed on a real client application. Describe them as portfolio/practice work during interviews.
